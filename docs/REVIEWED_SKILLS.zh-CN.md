# 已审核的技能指令

[English](REVIEWED_SKILLS.md) · [简体中文](REVIEWED_SKILLS.zh-CN.md)

Owner 现在可以在 **设置 → 技能 → 安装技能** 中粘贴全文，或选择不超过 12 KiB 的单个文件。
填写语义版本号后，它会先成为候选技能。选中该技能并核对完整正文，填写理由后选择验证，再明确同意将此版本发送给已配置的模型。Server 会将审核决定绑定到正文的 SHA-256。

示例文件：

```markdown
---
name: evidence-report
description: 根据任务明确提供的来源撰写简短报告。
license: MIT
---
使用已有工具读取任务提供的来源，区分来源事实和推断。
如果报告工具可用，撰写 Markdown 报告，并说明缺失的证据。
```

然后向该员工提交原生任务，例如：“使用 evidence-report，根据 https://example.com/ 整理简短报告。”
仍需配置并启用受支持的模型。Agent 会先看到有界的技能摘要，按需调用 `read_skill` 读取完整正文，再使用已有工具完成流程。读取事件只记录技能 ID、版本状态与摘要值，不将正文复制到审计记录。

## 审核与执行边界

- 每个版本的正文固定。修改内容需要导入新版本并重新审核；旧版本不应继续使用时，请暂停或永久撤销。
- 候选、暂停、撤销、未核对正文摘要值和其他员工的技能不会交给模型。暂停或撤销会使已读取的引用失效，后续步骤、工具调用及最终结果发布都会重新检查。恢复后产生新的状态版本，旧任务不能恢复使用旧引用。已经发送给模型的内容无法追回。
- 每个任务最多提供 8 个技能摘要，总计 4 KiB，并标明是否省略；最多读取 2 个完整文件。现有 5 轮模型、8 次工具调用上限保持有效。
- 当前执行范围是无需额外 Worker 能力或技能依赖的单文件指令流程。`allowed-tools` 只作说明，不会授予工具或网络目标。不会运行脚本、解压归档、读取附属文件或新增电脑权限。
- YAML 元数据采用固定版本 Agent Skills 标准并限制字段与大小，拒绝标签、锚点、别名、指令、重复或未知字段及控制字符。Markdown 正文完整保存，界面以转义文本显示。
- 员工包仍只导出技能元数据，不携带正文或启用状态。接收方需要另行导入并审核文件。
