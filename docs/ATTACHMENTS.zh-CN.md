# 频道附件与内容处理

可通过输入框文件选择、拖放或粘贴图片添加附件。每条消息最多八个附件、合计 20 MiB；文本与代码单文件 256 KiB、PNG/JPEG 5 MiB、文档与媒体 10 MiB。Server 会检查文件名、格式标记与 SHA-256。原始文件不可变，并按频道隔离。

## 能做什么

| 输入 | 操作 | 在哪里处理 |
| --- | --- | --- |
| UTF-8 文本、代码 | Bot 分页读取 | 仅当前任务明确附带的附件 |
| DOCX、XLSX、PPTX、ODT、ODS、ODP | 从附件操作中提取文档文字 | Server 本地 officeparser；不执行宏，不展开嵌入附件 |
| PDF | 提取文字，需要时填写 PDF 密码 | Server 本地 PDF.js；密码只用于这次操作，不保存 |
| PNG、JPEG | 识别图片文字 | Server 本地 Tesseract；自带英语与简体中文数据，不上传图片或临时从 CDN 下载 |
| MP3、WAV、M4A、MP4、WebM | 明确点击后发送给 OpenAI 转写 | 需要启用 OpenAI 连接；模型密钥只留在 Server |

附件卡片可以提取文字、识别图片、转写或下载原文件。Office 文档和媒体应先处理，再发给 Bot；处理后通过 `read_attachment` 分页读取，因此不依赖模型本身支持这些文件格式。未处理的 PNG/JPEG/PDF 仍可使用已有的 OpenAI/Anthropic 二进制输入能力。卡片显示处理后的字符数，并标明是否截断。处理失败或取消不会删除原文件，也不会替换已有的有效处理结果。

PDF 提取读取文件已有的文字层。纯扫描 PDF 暂不自动逐页渲染并 OCR，需要先提供对应页面的 PNG/JPEG 图片。OCR 与转写可能有误，原文件始终可供核对。不支持旧版二进制 DOC/XLS/PPT，也不支持 Office 文档密码加密。

## 处理限制与数据边界

Server 最多同时处理两个附件。解析放在独立 Node Worker 内，分别限制堆、栈、输入、图片像素、解压体积、ZIP 条目、表格展开单元格、输出长度与耗时。堆限制不是完整的操作系统内存沙箱，原生库和 Wasm 仍可能单独分配内存。图片最多 1,600 万像素，ZIP 解压最多 32 MiB、2,000 个条目，表格最多展开 100,000 个单元格；每次输出最多 262,144 个 UTF-16 字符，PDF 最多 200 页，文档提取最多 30 秒、OCR 最多 60 秒。超限会停止处理，不执行文档 HTML。

派生文字单独保存，并记录源文件 SHA-256、处理方式、时间与截断标记。Bot 将附件当作不可信任务数据，附件内容不会授予权限。PDF 密码不保存。媒体转写只有明确点击才会执行，上传、查看或创建任务都不会自动将媒体发给第三方；请求限时 90 秒、不跟随重定向，并限制返回体积。

## 管理与恢复

频道文件管理提供可用附件和回收站。移到回收站会保留原文件，已有任务仍可以继续读取；恢复后重新出现在可用列表。手工清理只删除进入回收站超过七天、且不再被消息或任务引用的文件。Server 无法检查引用时拒绝清理，不会默默删除。没有后台自动清理。

桌面版下载原件仅向主进程传递精确的频道与附件 ID。主进程读取并校验文件，打开系统保存对话框，重新确认登录连接，再以不覆盖已有文件的方式保存。网页版同样校验哈希，并将附件当作普通下载字节；两条路径都不执行附件中的 HTML。

## 已验证与未验证

真实解析测试使用本地生成的 DOCX/XLSX/PPTX/ODT、AES-256 加密 PDF，以及配合离线语言数据的 OCR 图片，并检查损坏容器、取消、错误密码、哈希不匹配、模型提供方限制、频道隔离、回收站引用保留与原生下载。媒体转写测试模拟 HTTP 返回，不能替代真实模型服务验收。Windows 原生结果以对应 CI 为准，macOS 本地测试不代表 Windows 真机通过。

## 没有可读文字的文档

解析器只返回空白时，文字提取会显示原因，原文件仍可下载，也不会标记为提取成功。
PDF 可能是扫描件或空白文档；提取 PDF 文字不会自动执行 OCR。可上传 PNG/JPEG 页面后主动选择
图片文字识别，或提供带有可读文字层的 PDF。只有部分页面可搜索的 PDF 仍可能只提取出部分内容，
提取成功不保证覆盖全部页面。

如果旧版本保存了空的提取结果，开始任务时会提示重新上传原件，提取可读文字，或主动附上受支持的
图片/PDF。程序不会悄悄将原文件替代空文本发送给模型。

处理后的文档、OCR 和转写与纯文本共用受审计的 `read_attachment` 工具，单独提供时也可读取。附件格式、媒体/扩展名限制和操作定义位于共享协议包。定时任务遵循[相同的引用生命周期](AUTOMATIONS.zh-CN.md#附件引用)。
