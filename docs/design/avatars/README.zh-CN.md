# OpenBot 无框头像系统 · v2

[English](README.md)

> 这是仓库所有者交付的源作品（v2）。应用据此绘制 v3：调整内容（耳罩款宽度、小尺寸规则、八种下颌色）见 [DESIGN.zh-CN.md](../desktop-ui-2026-10/DESIGN.zh-CN.md#bot-头像v3)。

本版以 OpenBot 原有机器人身份与前一轮视觉探索为基础，重新绘制可编辑 SVG 路径。交付范围是设计资产，尚未替换应用组件或本机安装版本。

## 文件与使用

- `assets/openbot-{round,relay,scout}-{light,dark}.svg`：标准稿，建议 32 CSS 像素及以上。
- `assets/openbot-{round,relay,scout}-{light,dark}-micro.svg`：16–24 CSS 像素专用稿，扩大眼睛；圆顶款加粗天线。24 与 32 之间优先使用 micro。
- `assets/manifest.json`：全部文件、配色与尺寸用途。
- `contact-sheet.svg`：可分享的总览设计板。

`light` / `dark` 指**头像所在界面的背景**：浅色界面用炭黑机器人，深色界面用暖白机器人。主题切换由使用方明确选择，不根据操作系统主题自动猜测。

所有 SVG 透明底，统一 `0 0 96 96` 画布，保留 silhouette、accent、eyes 命名结构。不含位图、字体、滤镜、脚本或外链，后续可直接在矢量编辑器里修改。插入时保留完整画布比例，不裁掉天线或耳朵，不加圆形/方形衬底；点击区域可独立扩大。

SVG 自带标题和描述。若相邻已有员工名称，装饰性 `<img>` 使用空 alt，避免重复朗读。多个 SVG 直接内联时，应为标题 ID 加唯一前缀，或移除内部标题并由外部组件提供可访问名称。

## 设计收敛

- 收薄彩色下颌，与机体共享外轮廓。
- 缩小天线球，让视觉重心回到眼睛和脸部。
- 统一胶囊眼语言，通过少量高低/倾斜变化表达性格。
- 耳罩款面部稍窄，平衡左右配件的视觉重量。
- 猫耳尖端做圆钝处理，减少小尺寸下的尖刺感。
- 同一角色、同一尺寸的深浅版本共享几何，仅更换颜色。

圆顶是推荐默认款；耳罩与猫耳是身份变体，不限定职业。任务状态仍由独立状态点和文字表达。旧版身体、移动方式和配件组合不在本次设计迁移范围内。
