# Desktop 界面实施计划

[English](IMPLEMENTATION.md) · [简体中文](IMPLEMENTATION.zh-CN.md)

目标：每个界面都与[已确认的画板](README.zh-CN.md)一致。所有者于 2026-10-01 决定界面只以本设计为准，
之前只换样式的工作不再作为参照。按步骤推进，每一步一个拉取请求，并附上与对应画板的渲染对比。

## 分工

同一文件范围只有一名实施者（见根目录 `AGENTS.md`）。跨范围的需求通过下方待办协调。

| 负责人 | 范围 |
| --- | --- |
| Claude | 界面：`apps/web/src/**`（组件、样式、Web API 客户端 `api.ts`）、界面测试、`docs/design/**` |
| Codex | 服务端与平台：`apps/server-python/**`、`packages/db/**`、`packages/protocol/**`、`packages/domain/**`、`apps/desktop/src/**`（主进程与 preload）、CI 与脚本 |

后端事项在其路由或桥接方法、domain/protocol 类型和测试合并，并写入 `docs/API.md` 后，界面才接入。
在此之前界面按设计呈现但不显示缺失的数据（隐藏、禁用或只读），绝不伪造。

## 每一步的完成标准

1. 在 1440×900 下布局、尺寸、颜色和文案与画板一致；手机宽度无横向溢出。
2. 保留现有行为和数据路径；不伪造 Server 没有提供的内容。
3. 更新或新增组件测试；`npm run check` 通过；不新增 Biome 警告。
4. 在拉取请求中附上与画板的渲染对比。
