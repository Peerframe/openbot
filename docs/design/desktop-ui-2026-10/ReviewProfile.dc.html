体验检查 · 第 4 条：Bot 档案页的重复信息

打开某个 Bot 的档案时，同一个 Bot 的头像、名字和标签在屏幕上出现了三次。建议：进档案页时右栏默认收起，需要时点顶部的名字胶囊再打开。

现在红框是同一份信息
1
2
3
  1. 顶部名字胶囊：头像 + 名字
  2. 档案页正文：大头像 + 名字 + 标签 + 介绍
  3. 右栏「Bot 信息」：又一个大头像 + 名字 + 标签（下面还有模型、电脑等，档案页「配置」里也有）
建议右栏默认收起，正文更宽
  • 只在档案页默认收起；单聊和频道里的右栏不变。
  • 点顶部名字胶囊仍能打开右栏（编辑头像、改名、通知开关都还在）。
  • 你手动打开过，就记住你的选择。
