# 独立开发主线

[English](DEVELOPMENT_TRACKS.md) · [简体中文](DEVELOPMENT_TRACKS.zh-CN.md)

这是 2026-09-22 方向的当前执行入口：无界面且可独立验证的 Agent 服务、共享官方客户端、可独立
维护的扩展。保留单仓库与现有技术栈；身份、权限、批准、审计和持久任务状态仍由 Server 掌握。
模块边界不能授予权限，也不能代替沙箱。

开发基线是 `main` 的 `ebce995`，不是旧工作目录的 `9cc73c9`。本文接替历史八小时计划的后续排期，
不改写历史阶段编号，也不表示整个产品路线已经完成。

## 主线与集成责任

| 主线 | 模块入口 | 当前工作包 | 验收结果 |
| --- | --- | --- | --- |
| R：Runtime 与无界面交付 | Server native-agent、PostgresAgentStore | R1：确定性 Server 旅程，续跑与可选学习回归 | 已鉴权任务完成并能下载报告；失败、取消、晚到结果、客户端断开均可验证，无需 Web、Electron 或付费推理 |
| C：客户端与状态契约 | ControlPlaneStore、workspace API、domain、只读示例 | C1：一致快照与明确重同步 | 持久字段和计数来自同一数据库快照；独立只读客户端处理重复、旧帧和重连；明确分页范围 |
| P：扩展兼容性 | Server 插件、独立 MCP 脚手架 | P1：共享预检与可理解的失败原因 | 授权前拒绝不支持的要求；独立成功/schema/认证/超时用例不依赖 OpenBot workspace |
| D：贡献者验证 | scripts、现有 CI、贡献指南 | D1：影子模式影响分析 | 复用 Turbo 官方依赖图；高风险、未知或失败自动建议全量；不跳过既有必需检查 |

每个工作包使用独立分支和工作区，由一个实现任务负责代码、回归测试、固定版本研究和中英模块
文档。共享协议、存储、安全路径先统一，再让客户端并行接入。集成任务负责公共清单、复用账本、
完整检查和跨主线回归；不虚构模块维护者或发布负责人。

以上是待开发工作，不是已交付功能。每项先定义有界验收旅程并找到复用账本，按 `AGENTS.md`
检查上游源码、发布、测试、issue 和许可后改变行为。权限、存储、外部动作继续失败时拒绝。
原生移动客户端、企业多租户权限、全平台电脑操作、扩展商业市场、所有权转移和办公室插件均不是
首批成果；它们仍在产品路线中显式保留，不能默认承诺已经支持。

## 贡献交接

可领取任务必须明确结果、非目标、入口、依赖、定向命令、失败用例和审查入口。尚未解决的架构题
不是新手任务。使用仓库测试与合成数据，不依赖私人聊天。成本分别记录开发 AI、产品推理、执行/CI、
维护者时间；没有实际计时和比较证据时，不声称影子报告已经降低了成本。

## 2026-09-22 集成证据

- 四条主线合并后，`npm run check` 本地通过，包含 Server/Web/Desktop 类型检查、测试及构建；
  原有需要特定环境的跳过项仍明确保留。
- `npm run test:runtime` 使用新建并自动清理的 PostgreSQL 容器、真实 Owner API 和确定性模型，
  90 项测试通过。
- `npm run test:workspace` 的 Server/订阅/读取器共 64 项通过；最终独立消费者另有 3 个 Node
  场景通过，包含代理静默断线超时。
- `npm run db:verify` 在本任务独立合成数据库中通过，覆盖迁移校验和在工作区列表、计数读取
  之间强制提交并发变更。
- 真实浏览器使用独立 Vite 入口、合成 Owner 与本次 Server 构建，已验证登录、完整计数显示，
  停止上游后页面明确显示 stale；Server 重启后无需重新登录，自动恢复 current。
- 独立复核覆盖 Runtime 改动、MCP 生产打包边界及快照取消/新鲜度；最终取消测试无需手动
  完成阻塞读取，也能让订阅退出。

CI 已在现有临时数据库 job 接入同一无界面旅程，并由 `db:verify` 执行快照验证；影响报告保留
全量门槛。本批没有验证远端 hosted CI、原生安装、真实付费模型质量或外部 OAuth 账户，也没有
发布版本。上面的后续工作包仍待开发。
