# C19：频道附件的有上限引用次数

复用现有频道附件、Python 消息读取和 OwnerTransactions，不新增依赖、表或迁移。
固定上游版本、官方 SQL 文档和比较见[英文记录](channel-attachment-reference-counts.md)。
PostgreSQL 在一次语句快照内分别统计消息和频道 Run 冻结指令里的规范附件标记，
同一条记录重复标记只计一次；映射后的 Work Task 不重复统计，原生 Owner Task 命名空间独立。
不把消息正文、标题或 ID 取回应用层。文件锁先于 Owner 事务，返回前再次检查权限。

每类计数上限 10,000，列表沿用 1,024 文件上限；超限直接拒绝，没有饱和值或部分结果。
数据库语句 3 秒、Owner 事务 6 秒上限约束大频道扫描，超时表示不可用，不能当作零引用。
引用次数不证明模型已经读取，也不授权清理。同步更新中英文 API.md。

返回前撤权及现有附件命名空间与下载语义。CI 的真实 SQL lane 已加入新测试文件。
