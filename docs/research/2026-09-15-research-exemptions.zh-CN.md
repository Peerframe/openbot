## 复用决定

以现有 Git 和 Node 检查器作薄适配，不增加依赖。增加豁免类别、原因、文档路径白名单，并保守
比较代码、链接目标和标记。无法取得完整变更时拒绝自动豁免。正常七字段格式保持兼容，不能用
豁免补足未完成的研究表格。

自动路径只覆盖普通 Markdown 文本。规则、ADR/研究记录、代码、配置以及受保护内容变化使用现有研究表格。
AGENTS 对纯源码排版免做新研究的规则不变：可引用模块已有研究并说明行为未变，无需新增研究。
Git 参数固定且 SHA 经过校验，输出有界，不把 PR 文字当 shell 命令，不增加网络或写权限。

## 源码引用

没有复制或实质改编上游源码、模板或 Git 实现，已有版权声明保持不变。

## 验证计划

接受正常研究表格、保留命令和链接的拼写/翻译、段落换行；拒绝无原因、未知类别、混合格式、
缺少 Git 证据、源码/配置/规则修改、可执行位修改、命令或链接修改。以临时 Git 仓库和合成
PR 事件测试真实 CLI、分叉基线、工作区误导、对象缺失和特殊文件名。

保持 `npm run research:check` 与完整检查衔接；CI check job 读取完整历史。CI 事件安排不变，
不承诺只编辑 PR 正文就自动重跑。同步中英文贡献指南，不增加产品运行或平台支持声明。

## 未解决的问题

自动检查不能证明翻译忠实或文字主张不变；它限制明显误用，语义判断继续属于原有 PR 审查。
