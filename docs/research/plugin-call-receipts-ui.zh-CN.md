## 复用决定

- 使用共享严格 schema，最多 256 条，拒绝其他任务与重复调用 ID，保持 Server 排序。请求同时
  受调用方取消信号和 10 秒超时约束。
- 每次仅一个请求，完成后间隔 5 秒，每次打开或显式刷新最多自动读取 24 次；已结束任务照常读。
  失败停止自动读取、保留已有记录并使用固定中文错误。刷新只发 GET；卸载或切换任务取消请求、
  定时器并忽略旧结果，渲染阶段也隔离旧任务数据。
- 未知和进行中记录优先；已终结记录默认折叠，列表限高，时间及版本详情也默认折叠。名称作为
  普通文本转义，不作为 HTML。
- 明确“收到答复”不等于独立验证外部结果。未知记录提示先到原服务核对，失败或取消也不代表
  外部动作未发生。保留已有、明确点击才创建新任务的入口，不增加调用重试。
- 原六个封闭场景和演示对已知任务返回空回执；新增 `plugin-receipts` 场景提供未知与已收答复样本
  及读取失败开关。该样本只在内存中，不冒充持久 Server 账本。

## 验证计划与限制

覆盖 schema、数量、任务关联、取消和超时；真实组件检查所有状态、审批事实、已结束任务读取、
轮询上限、请求不重叠、任务切换、卸载与 StrictMode、错误后保留记录及显式只读刷新。
真实浏览器检查正式 RunInspector 的未知、已收答复、错误及窄屏；复查旧六个场景。
执行定向测试、Web/Desktop typecheck 和 `npm run check`。使用说明同步 CLIENT_FIXTURES 双语。

证据仅覆盖共享客户端展示和读取生命周期，不代表新外部效果保证、原生 Desktop 运行或真实
第三方工具执行。提供方核对流程与账本管理仍由后续 Server 工作实现。
