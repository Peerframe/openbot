## 代码功能库与 Hermes 对照

以下是该历史检查点的代码审查结果，不代表今天的实现状态。

| 能力 | 当时证据 | 当时剩余工作 |
| --- | --- | --- |
| 定时自动化 | `automations.ts`、`postgres-automation-store.ts` 已有 15 分钟至 7 天间隔、暂停/恢复/删除和持久化派发 | 自然语言建计划、cron/时区语义、外部平台投递、多 Server 协调 |
| 技能库与迁移 | 版本化元数据、模板导入/导出、单文件 SKILL.md 导入、绑定正文摘要的全文审核、原生任务受限读取及执行中撤销 | 脚本、附属资源、正文迁移、原生任务技能依赖和真实模型效果 |
| 消息网关 | 运行时没有 Telegram/Discord/Slack/WhatsApp/Signal 网关适配器 | 先完成一个平台，接入 Server 身份/审批、入站幂等和授权回复 |
| 委派与并行 | 原生 runner 可同时运行最多两个任务；没有隔离子 Agent 协议 | 父子权限、隔离上下文、取消、预算、汇总、恢复；独立任务并发不等于委派 |
| 电脑交互 | URL 截图及默认关闭、经过 Server 审批的可信测试站点单按钮点击；见[受控浏览器](CONTROLLED_BROWSER.zh-CN.md) | 浏览器出口隔离、签名单次执行凭据、原生输入、全局独占接管和其他真实设备测试 |
| 多运行环境 | 已有 Server 容器与 Worker 路由，没有 SSH/Daytona/Modal/Singularity 适配器 | 按研究复用流程选择一个后端，验证生命周期、隔离与清理 |
| TUI 与对话回溯 | Web/Desktop 频道和有界近期上下文 | 完整终端交互、全文/语义检索、后台整理、Honcho 类用户建模 |
| 训练/研究导出 | 已有运行事件与审计记录 | 脱敏轨迹导出、可重放格式、质量筛选和保留策略；审计日志不等于训练集 |

学习方向明确借鉴 [Hermes Agent](https://github.com/NousResearch/hermes-agent/tree/63279301bcbdc185c1b07b98a9312eb0c862f26d)。

## 当时尚未完成的验收

1. **真正公开安装：**补齐捆绑 PostgreSQL 原生依赖与源码对应、LGPL 源码/重新链接证据，
   再进行维护者发布审查、main CI 和公开安装下载。补签名、公证与干净设备安装/升级/卸载证据。
   目前继续明确提供开发产物入口。
2. **真实可用任务：**在合适网络中，用真实支持的模型和公网资料完成报告、停止与经验复用，
   将夹具证据升级为真实使用证据。
3. **技能资源：**已实现审核后的独立指令加载；脚本、附属资源与正文迁移仍需独立的执行边界审查。
4. **受控电脑操作：**已实现审批后单按钮点击流程；先补浏览器出口限制与其他设备验证，再扩大平台声明。
   参见 [Provider 验证](PROVIDER_CONFORMANCE.zh-CN.md)。
5. **生态：**先一个消息网关，再按实际工作流补委派或另一个后端，不再堆只有声明的适配器。

该检查点的 macOS 可运行本地 Server；Windows/Linux 是远程客户端。退出桌面会停止应用托管的本地服务；
无人值守自动任务需要持续在线的 Server。自动更新、完整备份恢复、三端本地 Server 均未完成。
