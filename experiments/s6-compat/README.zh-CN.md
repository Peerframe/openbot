# S6 兼容夹具

[English](README.md) · [简体中文](README.zh-CN.md)

本实验用合成输入调用现有 TypeScript Server 存储、原生执行器与 MCP 服务。它创建专属临时
PostgreSQL 容器，并用现有官方 SDK 示例提供带身份验证的本机 MCP 端点，无需模型账号。

在仓库根目录使用项目支持的 Node 版本，并启动 Docker：

```sh
npm ci --ignore-scripts --no-audit
node experiments/s6-compat/run.mjs
```

入口构建依赖包、检查专属测试类型、运行六个探针并删除自建容器。PostgreSQL 使用现有无界面
验收脚本固定的 17.11 镜像。命令不接受外部数据库地址、不读取 `.env`，也不向测试子进程传入
产品或模型凭据。缺少依赖或断言失败会返回非零状态，不会静默跳过数据库测试。MCP 临时文件
只有合成凭据，每项测试结束后删除。

| 探针 | 实际证据 |
| --- | --- |
| `S6-GRANT` | 真实委派子任务不能使用父 Bot 的 MCP 授权；单独授权子 Bot 后，重开存储仍可调用。 |
| `S6-CANCEL` | 父任务取消持久化；重开存储后，即使调用者省略祖先字段，子任务的工具调用与迟到发布仍被拒绝。已完成后代的回复保留。 |
| `S6-APPROVAL` | 父任务取消后，等待中的子任务写入不能获批；调用方显式中止后清除待审批请求，不产生派发。 |
| `S6-MCP` | HTTP 401 阻止调用与目录刷新，且不重试；重开存储、端点恢复后，单 Bot 授权撤销仍有效。 |
| `S6-CONFLICT` | 独立根任务 Bot 可同时运行；同 Bot、同频道的根任务通过不同数据库连接领取时仍串行。 |
| `S6-BUDGET-BASELINE` | 父任务读取 3 次网页、子任务读取 2 次，二者按现有每 Run 预算完成。共享 Task 预算准入仍是 S6 待实现要求。 |

六项探针通过包含现有每 Run 预算的行为记录，不代表共享 Task 预算已验收。当前架构与异步协作
文档规定每 Run 最多 4 次网页调用，能力迁移清单却称预算共享；研究文档记录了这处不一致。
Task 预算准入和总额度确定后，应将现状断言替换成正式验收契约。基础设施或其他错误不会被当作
预期失败吞掉。

重载测试在同一测试进程里重建数据库连接、存储和服务对象，只证明持久记录继续生效。尚未运行
进程崩溃恢复、Temporal、Python 控制层/Runtime 接线、浏览器和文件执行、OAuth 刷新令牌流程、
未知外部效果对账或模型数据迁移。资源冲突证据仅覆盖现有根任务领取串行化。

夹具直接调用服务/存储接口，位于产品 HTTP 路由认证之下；Owner 路由认证和部署后的取消通知
需要另行验收。`S6-APPROVAL` 在取消持久化后显式发送调用方中止信号，产品需负责连接该信号。

[研究与交接](../../docs/research/s6-compatibility.md)记录了固定依赖/源版本、模型字段映射与
S2/S3/S4 接口依赖。这些测试只在实验目录，`npm run check` 不会自动运行它们；交接时应运行
两个命令。整合者获得共享工作流修改范围后，可将实验命令加入使用临时 Docker 环境的 CI 作业。

本次不改变产品默认配置、迁移历史或 S6 阶段状态。
