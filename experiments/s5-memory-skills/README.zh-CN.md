# S5 有范围记忆与技能审核实验

[English](README.md) · [简体中文](README.zh-CN.md)

这套独立合成夹具展示：纠正 → 候选经验/技能 → Owner 审核 → 新任务效果对比 →
暂停与恢复 → 终态撤销 → 删除。它提供 S5 的第一份离线证据，不代表 S5 已完成。
学习与来源追踪方向受
[Hermes Agent](https://github.com/NousResearch/hermes-agent/tree/63279301bcbdc185c1b07b98a9312eb0c862f26d)
启发。详见[研究与 S2 接口记录](../../docs/research/s5-memory-skills.md)。

后续[Python 控制层选择接口](SELECTION_PORT.zh-CN.md)复用本夹具，
补充绑定 Task 的不可变上下文和当前版本/来源重新校验。

## 复现

在仓库根目录使用 Python 3.12+。无需安装依赖、凭证、网络、模型、数据库、产品配置或服务：

```sh
python3.12 -B -m unittest discover -s experiments/s5-memory-skills -p 'test_*.py' -v
python3.12 -B experiments/s5-memory-skills/probe.py
```

需要保留完整报告、生成的候选 SKILL.md 和各阶段 CSV 时，指定一个**尚不存在**的目录：

```sh
python3.12 -B experiments/s5-memory-skills/probe.py --output-dir /tmp/openbot-s5-evidence
```

`report.json` 包含实际与预期输出、夹具摘要、候选审核摘要、来源身份、作用域、消费引用、
拒绝原因和不含内容的生命周期事件。导出后重新打开 CSV 校验摘要和长度。
亚分金额案例保留选择/消费的技能引用，但不产生文件。
已提交的[本地报告](evidence/local-result.json)只含合成数据。

## 实验设计

候选生成只读取 `fixtures/training.json`，从两条纠正样例推导固定十进制倍数。
规则限于 1–1000 的整数倍数，保持行 ID 和顺序，要求结果恰为整数。
生成的 SKILL.md 描述该规则；解释器使用同一份经摘要绑定的结构化规则，
不解释任意 Markdown、不执行代码、不调用 LLM。

`fixtures/held-out.json` 独立保存销售、退款/零值两个新 CSV 任务及亚分金额拒绝案例。
Task、Run 和行 ID 与训练不重叠。解释器只接受任务输入，独立评分器读取预期答案。
即使通过审核，错误倍数负例仍得 0/3。基线复现原始缺陷：只改列名，原样复制美元数值。

记忆和技能各有状态。记忆初始待审核，共享默认关闭；Owner 可单独审核并开启检索。
技能也需要单独审核，同时绑定版本、Markdown、推导规则、来源和作用域的整体 SHA-256，
并检查当前分配修订号。此整体摘要属于实验格式，不替代产品现有的 SKILL.md 内容摘要。

| 状态变化 | 后续行为 |
| --- | --- |
| 候选 → 已验证 | 必须匹配 Owner、当前修订号和整体摘要 |
| 已验证 → 暂停 | 技能与衍生记忆均停止返回；记忆修订号递增 |
| 暂停 → 已验证 | Owner 重新审核；新修订号使旧引用失效 |
| 候选/已验证/暂停 → 撤销 | 终态，衍生记忆保持不可检索 |
| 删除经验 | 移除当前记忆及衍生技能的文本、规则、摘要；仅留 ID 墓碑和不含内容的审计 |

这项保守联动策略需在产品接入前确认，避免撤销经验经记忆路径重新出现。
删除仅作用于当前内存记录；原始合成夹具、导出证据和此前返回的上下文属于其他保留范围，
不会被该方法删除。

检索首先严格匹配 Owner/Bot/workspace/task kind。
workspace/task kind 是**合成策略维度**，当前 S2 work Task 投影没有这些字段。
范围内按 CSV、dollar、cent、refund 的单复数关键词重合排序，至少命中两项。
它验证范围先于排序、稳定顺序、显式共享和上限，不能代表通用语义检索、多语言相关性或生产方案。
查询最多 512 字节；最多返回 8 条且合计不超过 10 KiB；经验最多 2000 字节；
CSV 最多 4096 字节/32 行；评测最多 16 个案例。

Owner 身份、来源事实和权限由受信夹具控制层提供。纠正不能添加授权字段。
模拟权限仅为 `csv.read` 和 `artifact.write`，技能文本无法改变权限。
网络操作会被拒绝；移除 `artifact.write` 后，即使技能已验证也不能产出结果。
解释器不执行真实网络或文件动作，独立 CLI 只向指定证据目录写文件。

## 已观察到的证据

本地日期为 2026-09-24，macOS / Python 3.12.13，
源码基线 `e176e90a9de3854f0bf745773b7996e7bd572c83`，
解释器 `decimal-scale-fixture/1`。

| 阶段 | 新任务通过数 | 技能应用 |
| --- | --- | --- |
| 基线 | 0/3 | 无 |
| 待审核 | 0/3 | 无 |
| 审核后 | 3/3 | 有；亚分金额拒绝产出 |
| 暂停后 | 0/3 | 无；衍生记忆也不可检索 |
| 恢复后 | 3/3 | 有；旧引用仍被拒绝 |
| 撤销后 | 0/3 | 无；衍生记忆也不可检索 |

新销售任务基线为 `2.37, 19.99, 10`，审核后为 `237, 1999, 1000`。
这些是确定性合成结果，不是模型质量统计。

16 项专属测试全部通过，覆盖来源损坏、非 Owner 审核、内容/规则变更、旧修订号、
四个作用域维度、无关查询、待审核/暂停/撤销排除、默认关闭共享、删除和防复活、
权限移除、训练评测分离、评分敏感性、拒绝产物与导出后字节校验。
独立审阅最初复现三个缺口：撤销后衍生记忆仍可返回、常见词造成无关命中、
拒绝结果遗漏技能消费引用；现在均已修正并纳入回归测试。

`npm run check` 通过，未改变的工作区任务复用了已有 Turbo 缓存。
数据库、真实供应商和原生平台测试按现有条件跳过，没有新增这些系统的验收证据。
Python 实验测试单独运行；共享脚本和 CI 不在本工作包修改范围内。

## 产品接入

Python S2 已有独立 work Task/Run/Artifact、认证后的任务快照、字节校验下载及受信完成发布。
应复用这些身份和存储；接入前需明确：

1. 完成后认证、幂等的纠正命令，绑定 Task/Run/Artifact/摘要/修订号。
2. 来源解析、访问与删除策略，复用现有产物校验。
3. 正式作用域字段，模型自行填写的范围不能成为授权。
4. work 检查点和最终发布的知识消费引用、当前修订号/摘要复查，以及撤销与发布的串行化点。
5. 审核冲突、衍生知识失效、拒绝/过期、版本回滚和保留语义。

通用候选队列、自由文本教学、可执行归档、回到旧版本、并发与持久化审核、
备份/供应商删除、模型投毒防护、真实任务质量及产品集成均未实现。
没有修改产品服务、S3 Runtime、S4 执行器、默认后端或部署。
